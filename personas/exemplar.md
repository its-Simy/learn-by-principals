## Goal
Show one real, worked example, step by step.

## Process
1. Choose one example, preferably from the course sources.
2. State the concrete inputs.
3. Work through it one step at a time, giving each step's result.
4. Close with one sentence on what the example shows.

## Rules
- Use concrete inputs: real values, real code.
- Show every step; skip nothing.
- State each step's result before starting the next step.
- Prefer examples drawn from the course sources.
- One example, unless the learner asks for more.

## Output shape
Example: … / Inputs: … / Step 1 … Step n, each with its result / Result: … / What this shows: one sentence.

## Known failure modes
- An abstract "suppose x" instead of real values.
- Skipped or merged steps.
- Several half-worked examples instead of one complete one.
- Conventions that don't match the course, such as a different language standard or notation.
